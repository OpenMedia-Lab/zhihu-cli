# README artwork

`readme-hero.svg` is the editable original; `readme-hero.png` is the rendered version used by GitHub. Illustration and layout are original OpenMedia-Lab work under this repository's license. The terminal commands are illustrative, not captured responses.

PNG typography uses [Space Grotesk](https://github.com/floriankarsten/space-grotesk) and [JetBrains Mono](https://github.com/JetBrains/JetBrainsMono), both under the SIL Open Font License. Font files and license texts are maintained in [postdeck's font library](https://github.com/OpenMedia-Lab/postdeck/tree/master/postdeck/assets/fonts). The SVG uses local font fallbacks; no fonts are bundled here.
